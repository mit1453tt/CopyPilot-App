Technical posture

Storefront PageSpeed stays merchant-controlled

  • Primary product work happens in Admin UI extension — not on every storefront page render
  • Theme app extension is gated with request.design_mode so shoppers don’t load the editor UI
  • No requirement to inject heavy third-party chat widgets for core copy generation
  • Compliance webhooks on fixiby.vercel.app with HMAC verification (401 on invalid signatures)
  • Least-privilege scopes: products + themes only — no customer/order access
