Data processing summary

Roles

Shopify mandatory compliance webhooks

Fixiby implements HMAC-verified endpoints for:

  • customers/data_request
  • customers/redact
  • shop/redact
  • app/uninstalled (recommended hygiene)

Production endpoints on fixiby.vercel.app:

  • POST /api/webhooks/compliance
  • POST /api/webhooks/app-uninstalled

Subprocessors (typical)

  • Shopify Inc. — Admin API, Billing, webhooks
  • Vercel Inc. — hosting for the public site and webhook handlers
  • Optional AI inference — product text / locale only

Merchant checklist

  1. Link Privacy Policy in Partner Dashboard → App listing
  2. Confirm SHOPIFY_API_SECRET is set on Vercel for HMAC verification
  3. Run shopify app deploy so TOML webhook subscriptions register
