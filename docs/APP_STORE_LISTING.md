## Detailed description

CopyPilot AI by Fixiby Software Technologies helps merchants create conversion-focused product listings without leaving Shopify Admin.

**What you get**
- SEO + AIDA sales copy (Title Case titles, emotional HTML descriptions)
- Meta title & meta description generation
- Image SEO (alt text) with approve-before-publish
- **SEO score + GEO score** (AI search readiness for AI Overviews / ChatGPT / Perplexity)
- Multi-market targeting and 6 languages on paid plans (TR EN ES FR AR ZH)
- Brand voice, media upload, and bulk generate + publish on higher plans
- Safe writes: never changes variants, inventory, or prices

**How it works**
1. Open CopyPilot AI in Admin
2. Pick country + language + keywords
3. Generate → review preview → Approve & publish
